## 디자인 재검토와 반영

입주민의 위치·인원 입력 라벨과 간격을 정리하고 입력 크기를 조정했다. 결과 카드 여백, 시설정보 구분, 데모 및 저장 상태 문구를 개선했다. 포커스 표시, 브라우저 확대, 동작 감소 설정을 지원한다. 작은 화면의 통계·버튼 줄바꿈 규칙을 추가했다.

화면 확인 중 관리자 신고 선택이 다시 렌더링되며 해제되는 문제를 발견하여 선택값을 유지하도록 수정했다. 시설이 없는 세대에도 상태 이름에 ‘대피공간’이 붙는 오해를 줄이기 위해 상태를 ‘세대 내 대기’로 바꿨다. 화점 지정만으로 연기 유입이 확인됐다고 읽히지 않도록 위험 상태 문구도 수정했다.

브라우저에서 입주민 입력·질문·결과, 관리자 사건 연결, 상황실 반영, 현장대원 화면을 확인했다. 데스크톱 브라우저 검증이며 실제 모바일 기기, 보조공학 기기, 전체 다크모드 색상 검증은 남아 있다. 뷰포트 변경이 브라우저에서 적용되지 않아 390px 실측 검증 완료로 기록하지 않는다.

## 자동 검증

Node 테스트 21개: 사건 격리, 종료·만료·주소 불일치, 신고 연결 및 재제출, 시설 버전·예외, 현장 상태 충돌, 저장 실패·탭 충돌, v4 이관, 가져오기, 백업 복구, 출력 이스케이프, 정적 캐시 자산 포함, 판정 분기 등을 검사한다. 판정 테스트에는 질문 조합 1,280개 검사가 포함된다. 이는 의료·소방 안전성 인증이나 실제 현장 정확도 검증이 아니다.

## 남은 실운영 과제

1. 서버 인증과 역할별 권한, 서버에서 검증하는 사건·점검 링크.
2. 서버 데이터베이스와 기기 간 동기화, 원자적 동시 저장, 감사 기록.
3. 실제 119 접수·전달 연동의 별도 설계. 현재는 전화 링크만 제공한다.
4. 모든 대피 규칙과 시설 사용 문구의 소방 전문가 승인 및 실제 사례 검증.
5. 신고·인원 데이터 보관 기간, 접근 통제, 삭제·복구 정책.
6. 실기기 반응형·오프라인 전환·접근성 및 다크모드 전체 검증.
