# 역할별 협의 반영 · 2026-11-06

입주민·상황실·현장대원 채팅의 최신 검토와 기존 역할별 검토 문서를 바탕으로, 화면에 상시 정보를 늘리기보다 필요한 업무를 여는 흐름을 보강했다.

## 적용

- 상황실: 전체 진행 사건의 미확인 긴급 메시지와 재확인 세대를 한 창에서 조회하고 해당 사건·세대로 이동한다. 경과 시간과 사유를 함께 표시한다.
- 상황실: 사건별 메시지 초안을 현재 페이지 메모리에 유지한다. 새로고침 이후 복원은 지원하지 않는다.
- 상황실: 새 위험 신고 재확인 시 현재 상태와 확인 방법·근거를 기록한다. 인명검색의 재확인은 별도 절차로 유지한다.
- 현장대원: 메시지의 대상 호수에서 세대 상세와 조치 기록으로 이동한다. 작성 중인 세대 기록의 이탈 확인은 유지한다.
- 입주민: 브라우저 저장과 상황실 담당자의 신고 열람 확인을 구분한다. 열람 확인은 해당 신고 버전에만 적용하며 재저장 시 초기화한다. 열람은 구조·조치 완료를 의미하지 않는다.
- 저장 계층: 이전 신고 버전의 열람 확인, 종료 사건의 확인, 근거 없는 재확인을 거절하며 저장 실패 시 기록을 되돌린다.

## 검증

- `node --test tests/core.test.cjs tests/kapt.test.cjs`: 42개 통과.
- 브라우저: 49층·층당 8세대 샘플에서 사건 간 초안 복원, 전체 긴급 업무에서 사건·호수 이동, 현장 메시지에서 4908호 상세 이동 확인.
- 브라우저: 입주민 상태 저장 → 상황실 열람 확인 → 입주민 열람 표시 → 재저장 후 미확인으로 초기화 확인.
- 재확인 근거 필수 및 인명검색 재확인 분리는 자동 테스트로 검증했다. 재확인 대화상자의 전체 UI 조합은 미검증이다.
