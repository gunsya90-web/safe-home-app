# 질문·시설 사용 안내 검토 — 2026-11-08

## 반영
- 질문 분기를 resident-config.nextQuestionIndex에 모아 실제 UI와 회귀검사에 공통 적용.
- 우리 집 화재는 Q2를 건너뛰고 Q3 현관 확인. 다른 층 화재·실내 연기 없음은 상황 관찰 대기. 화재 위치 모름은 추가 질문 유지.
- 계단 대피 A는 현관 통과 가능과 지상까지 안전한 경로 응답 모두 필요. 경로 미확인·차단은 시설 확인 또는 구조요청으로 분기.
- UI 응답 '많음', '화염'을 엔진 내부에서 정규화. 우리 집 화재와 실내 다량 연기·화염은 critical.
- 모르는 현관 응답은 needsVerification. 충돌하는 화염·위험 경로 응답은 B 조기 반환 방지.
- 단지 공공시설은 시설 카드 참고정보이며 판정 입력으로 사용하지 않음. 세대별 자료만 C/D/E 판단에 사용.
- 대피공간은 접근 확인 제목으로 표시. 구형 결과의 욕실로 일률 이동하는 문구 삭제. D/E의 시설 순위와 맞지 않는 설명 수정.
- 표시되는 6종 시설 카드는 키보드로도 열리는 dialog. 주의사항, 3단계, 출처, 전화, 닫기·초점 복귀. 안내 열람은 답변이나 신고 상태를 변경하지 않음.

## 검증 및 한계
실제 질문 종료 경로 129개 × 시설조건 4종 = 516개 판정 검사 통과. 총 자동 테스트 71 통과, 브라우저 자동 테스트 2개는 런타임 미설치로 미실행. 실제 브라우저 시설 클릭·안내 표시 확인. 이는 응답 분기와 화면 기능의 검증이며 실화재 안전성 인증이 아니다.
시설의 현재 접근 가능 여부, 피난자의 이동 능력과 인접 세대 상태는 수집되지 않는다. C→D→E 우선순위는 최적 경로 판정이 아니다. 설치만으로 안전한 사용을 보장하지 않으며 제품별 조작법·현장대원 안내가 필요하다. 옥상 자동추천 G는 현재 입주민 질문에서 도달하지 않는다. 대구 전체 세대별 피난시설 현장검증과 소방 전문가의 최종 검토는 미완료다.


## 후속: 단지 시설 확인 질문
단지 설치·일부 설치는 후보 제시에만 사용한다. 공용 경로로 대피가 어렵고 시설 후보가 있으면 대피공간→경량칸막이→하향식 피난구 순서로 현재 설치·접근 여부를 묻는다. 경량칸막이와 하향식 피난구는 인접 세대로 이동 가능한지도 포함한다. yes만 현재 판정의 시설 true로 처리하며 no·unknown은 null로 유지한다. 시설 확인응답은 answers.facilityChecks에 저장하고 시설 원장·사건 스냅샷은 수정하지 않는다. 단지 일부설치의 원래 조사시점과 설치세대는 미확인이다. 질문 재시작 시 확인응답을 초기화한다. 로컬 실제 브라우저에서 센텀힐즈 후보→yes→대피공간 이동 결과 확인. 자동 테스트 72 통과, 2 미실행.
