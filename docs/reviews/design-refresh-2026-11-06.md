# SAFE-HOME 디자인 개편 — Quiet Operations

2026-11-06 사용자 요청: 외부의 좋은 UI를 참고해 기존 기능을 유지하면서 심플하고 직관적인 전체 디자인으로 개편.

## 참고와 해석

- Linear, How we redesigned the Linear UI: https://linear.app/now/how-we-redesigned-the-linear-ui — 사이드바·탭·헤더·패널의 시각적 잡음 감소와 위계. 세이프홈에서는 회청색 바탕, 흰 작업 영역, 절제된 파란 강조색으로 해석.
- IBM Carbon UI shell: https://v10.carbondesignsystem.com/components/UI-shell-header/usage/ — 제품 공통 탐색 구조. 사건 운영과 자료·관리 메뉴를 분리하고 현재 메뉴를 표시.
- Atlassian navigation layout: https://atlassian.design/components/navigation-system/layout — 탐색·본문·상세 영역과 반응형 탐색. 작은 화면은 메뉴 펼치기와 본문 재배치 적용.

외부 라이브러리/폰트/이미지 의존성을 추가하지 않았고, 기존 기능의 DOM과 이벤트를 보존했다.

## 적용 범위

- 공통 표현: css/workspace-refresh.css.
- 업무 메뉴: js/workspace-refresh.js. 상황실, 현장 활동, 건물·시설 자료, 공공자료 검토, 사건·링크 관리. 기존 주소로 이동하며 선택 메뉴 표시와 모바일 메뉴 펼치기/닫기 제공.
- 6개 HTML에서 공통 CSS/스크립트를 연결. index.html은 관리자 역할에서만 업무 메뉴 노출. 입주민/시설점검 등 외부 역할 링크는 공통 업무 메뉴 없음.
- 기존 index.html의 사건별 입주민·현장·시설 링크, 관리자 로그인, 발급/복사/유효기간/백업·복구 기능 유지.
- 입주민 기본 디자인 색상 및 모서리 기본값만 변경. 사용자가 저장한 기존 테마 설정은 유지. 큰 글자 설정 동작 확인.
- 서비스워커 캐시 버전 갱신 및 새 공통 자산 캐시 목록 추가.
- 판정·저장소·신고·메시지 처리 로직은 수정하지 않음. 실제119·다중기기 연동을 추가한 것이 아님.

## 검증

- 핵심 테스트 59개 통과, 첫 실행에서 Playwright 미탐지로 UI 2개는 건너뜀.
- NODE_PATH 지정 후 입주민 UI 검사 통과: 위치 확인, 인원/이동지원 유지, 저장 성공·실패 요약.
- 상황실 UI 검사는 테스트21행의 큐 전환 후 초안 기대값에서 실패. 새 CSS/JS를 빈 응답으로 제외한 기준 실행에서도 동일하게 실패. 기존 기능/테스트 기대값 차이로 분리 기록하고 이번 디자인 범위에서 로직·테스트를 바꾸지 않음. 따라서 전체 검사 통과로 보고하면 안 됨.
- 실제 Chrome 별도 임시 프로필에서 상황실/현장/시설/공공자료/관리자/입주민을 1600,1024,768,375px 너비로 확인. 페이지 가로 넘침 없음, pageerror 0.
- 샘플 사건으로 세대 현황 렌더링 확인. 실제 사용자 브라우저 저장소에 샘플을 쓰지 않음.
- 375×667 입주민 첫 화면: 시작 버튼 y465~519, 위치모름 y529~577, 전화 y599~655.
- 관리자 로그인 및 다크모드 토글, 모바일 메뉴에서 현장 화면 이동, 외부 시설점검 링크의 업무 메뉴 비노출, 입주민 글자20px 설정 확인.
- git diff --check 및 변경 JS 구문 검사 통과.

## 후속 과제/경계

공통 디자인과 페이지 탐색을 구현한 단계다. 모든 모듈을 단일 SPA로 합치거나 메뉴 전환 간 사건·세대·미저장 초안 유지 계약을 새로 구현하지 않았다. 기존 페이지 이동과 각 모듈의 저장 정책이 유지된다. 외부 링크의 서버 권한, 실제 메시지 발송, 기기 간 응답 수집도 별도 작업이다.

iOS/Android 실제 키보드·스크린리더 검증은 남아 있다. 운영 권한은 CSS 메뉴 숨김으로 보장되지 않으며 기존 로컬 데모 범위를 유지한다.

배포/push 없음. 대장 채팅이 작업 중인 공통 데이터와 다른 역할의 기존 미커밋 수정은 보존.
