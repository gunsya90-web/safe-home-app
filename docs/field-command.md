# 현장 지휘 앱

접속: `/field.html`. 입주민 디자인 앱(`/resident.html`)과 **같은 프로토콜·주소·포트·브라우저 프로필**에서 사용합니다. 예: 두 앱 모두 `http://127.0.0.1:4174`.

## 사용

1. 우측 상단에서 대원 이름·팀을 설정합니다. 이름은 탭 세션에 보관됩니다. 데모용 자기 입력 정보이며 인증된 신원이 아닙니다.
2. 사건/신고 대상 선택에서 진행 사건 또는 미확정 신고 건물을 선택합니다.
3. 작전도의 세대를 선택하여 입주민 원문과 현장 확인을 봅니다.
4. 현장 상태·연락 상태·구조/잔류 인원·메모를 저장합니다. 미확인 인원은 공란, 확인된 0명은 0으로 입력합니다. 안전 확인 상태는 잔류 0명 확인을 요구합니다.
5. 활동 기록 또는 세대 상세에서 수정자·팀·시각·변경 전후 값을 확인합니다.

미확정 신고도 현장 기록이 가능합니다. 신고 없는 세대는 관리자에서 사건을 확정한 뒤 수정합니다. 입주민의 새 응답은 신고 원문에 반영되고 현장 기록을 덮어쓰지 않습니다. 새로운 critical 신고나 상충 상태는 추가 확인으로 표시합니다. 입력 중 새 데이터가 도착하면 초안을 유지하고 최신 데이터 재확인 전 저장을 거절합니다.

## 배치 자료

기존 데모 건물은 층×세대/층, 가져온 건물은 등록 호수 목록을 바탕으로 **개략도**를 그립니다. 실제 좌우 배치라고 표시하지 않습니다. 등록 호수가 없는 칸은 새 세대를 만들지 않습니다.

실제 배치는 건물 자료에 다음 형식으로 지정할 수 있습니다. 사건 생성 시 건물 스냅샷에 포함됩니다.

```js
tacticalLayout: {
  floors: [
    {label: '5F', cells: ['501', '502', {label: '계단'}, '503', null, '504']},
    {label: '4F', cells: ['401', '402', {label: '계단'}, '403', null, '404']}
  ]
}
```

평면도 표시·배치자료 업로드 UI는 아직 없습니다. 미등록 평면도는 임의 도면으로 대체하지 않습니다. 세대별 시설은 기존 사건 세대의 `afpOverride`만 표시하며 동 공통정보와 입주민 디자인 샘플은 세대별 검증 자료로 간주하지 않습니다.

## 수정 위치

- `field.html`: 공통 헤더·작전도·수정자 대화상자
- `css/field.css`: 상단 색상·세대 크기 토큰, 반응형 디자인
- `js/field.js`: 작전도·신고·세대 상세·로그 UI
- `js/store.js`: `updateFieldObservation`, 원문과 현장 확인 보존, 구조화 로그·충돌 검사

화면의 로그는 브라우저 저장소에 보존되며 변조 방지 감사 로그나 서버 인증을 제공하지 않습니다. 다른 기기 간 공유는 서버 연결 후 지원해야 합니다. 기존 관리자의 전체 기록 백업에 현장 기록과 로그도 포함됩니다.

## 태블릿 구성

첨부한 현장대원 화면의 현황·층별 세대·상세 구성을 태블릿에 맞춰 재배치했습니다. 768px 이상에서 작전도와 세대 상세를 나란히 표시하며 각 영역을 독립적으로 스크롤합니다. 상단 탭에서 작전도, 입주민 신고 목록, 활동 기록을 전환합니다. 1194×834, 1024×768 가로 및 768×1024 세로 화면을 확인했습니다. 스타일은 `css/field.css`의 TABLET EDITION 구역에서 세부 조정합니다.

## 고층·다세대 작전도

49층 × 층당 8세대(392세대)로 브라우저 검증했습니다. 층 바로가기, 전체/주변 10개/5개 층 선택, 발화층 이동, 정확한 호수 검색 시 해당 층 이동, 압축 보기 및 폭 맞춤을 지원합니다. 글자가 지나치게 작아지는 폭에서는 가로 스크롤을 유지합니다. 등록된 층과 호수를 기준으로 하며 검증용 392세대는 사용자 저장소에 추가하지 않았습니다.

## 2026-10-20 자료 검토 반영
- 세대 상세의 인명검색은 세대 안전 상태와 별도로 저장한다. 확인 공간과 수정자·팀·시각·변경 전후를 남긴다. 완료 후 새 critical 신고에는 재확인을 표시한다.
- 시설·평면도와 건물 특화구조는 접힌 상세 항목으로 제공한다. facilities.html에서 세대별 설치 여부·위치·확인일·출처·확인자·이미지를 등록한다.
- 진행 사건은 생성 당시 시설자료를 유지한다. 이후 시설 수정은 새 사건에 적용한다. 기존 사건에 자료가 없으면 미등록으로 표시한다.
- 입주민 결과 화면에서 현재 위치·인원을 선택 입력한다. 데이터 공유는 같은 출처의 같은 브라우저 범위다.
