# 입주민 디자인 앱

`/resident.html`에서 실행합니다. 기존 `/` 앱과 별도로 검토할 수 있습니다.

## 디자인 수정

- `css/resident-design.css`: 상단 `:root`의 색상·모서리·글꼴 토큰, 이후 화면별 클래스.
- `js/resident-config.js`: 질문 제목·선택지, 건물 ID → 호수별 시설자료.
- `js/resident-design.js`: 화면 컴포넌트, 결과별 문구, 분기·저장·음성 안내.
- `resident.html`: 데스크톱 설명 영역, 공통 헤더, 디자인 패널.

화면 우측 상단의 설정 버튼에서 강조색·네이비·모서리·본문 크기를 조정하고 세 화면을 미리 봅니다. 설정은 현재 브라우저에 저장되며 파일 자체는 변경하지 않습니다.

## 데이터와 범위

행복아파트 101동 501호(하향식 피난구), 502호(대피공간)는 **디자인 검토용 예시**입니다. 다른 세대는 미확인으로 표시하며 동 전체의 기본 시설정보를 상속하지 않습니다. 실제 세대별 자료는 `resident-config.js`에서 교체할 수 있습니다. 관리자 시설 편집 화면과의 연동은 후속 작업입니다.

판정은 기존 `SAFEHOME.decide()`를 재사용합니다. 우리 집 화재는 실내 유입 질문을 건너뛰고 현관 상태를 묻습니다. 다른 곳 화재·연기 없음은 대기, 안전한 지상 경로 확인 시 계단 대피, 경로 미확인 시 세대별 시설정보에 따른 결과를 표시합니다. 시설 이용 가능 여부를 실시간 검증하지 않으며 실제 화재 행동 판정의 현장 적합성 검증은 별도로 필요합니다.

상태 저장은 사용자가 버튼을 누를 때 기존 저장소의 미확정 신고로 저장합니다. 실제 119 신고나 외부 전송은 하지 않습니다. 사건 링크로 진입하는 기존 앱의 대체 화면은 아니며, 이 독립 화면은 사건 파라미터를 사용하지 않습니다.

119 전화는 `tel:119`, 음성은 브라우저 내장 음성 합성을 사용합니다. 위치를 모르는 경우 안내는 가능하지만 위치 없는 기록은 저장하지 않습니다.

기존 서버가 실행 중이라면 새 경로 반영을 위해 재시작하거나 별도 포트를 사용합니다.

```sh
PORT=4174 node tools/serve.cjs
```
